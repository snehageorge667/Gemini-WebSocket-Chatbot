# Gemini WebSocket Chatbot

A real-time chatbot built using **Flask + Socket.IO (WebSocket)** for backend
and **React** for frontend, integrated with **Google Gemini API**.

## 🚀 Features
- Real-time WebSocket communication (no REST polling)
- Floating chat bubble UI
- Typing indicator
- Clear & close chat options
- Free-tier Gemini model support

## 🛠 Tech Stack
- Backend: Flask, Flask-SocketIO
- Frontend: React
- Communication: WebSocket (Socket.IO)
- AI: Google Gemini API
